# Бизнес-правила прототипа

Источник: [tz.md](tz.md) §19.

| ID | Правило |
|----|---------|
| **BR-01** | На заявку — только одно активное назначение. |
| **BR-02** | На занятую бригаду новую заявку назначить нельзя. |
| **BR-03** | Автоподбор рассматривает только свободные бригады. |
| **BR-04** | Для телеинспекции — только бригады с соответствующим оборудованием. |
| **BR-05** | Нет подходящей бригады → автоматическое назначение не выполняется. |
| **BR-06** | Диспетчер может изменить рекомендацию системы. |
| **BR-07** | При изменении рекомендации обязателен комментарий. |
| **BR-08** | Бригадир не может выполнять назначение. |
| **BR-09** | Если заявка изменилась после открытия — устаревшее назначение не выполняется; показывается конфликт. |

## Следствия для UI

- Конфликт → modal «Назначение изменилось», без второго назначения.
- Нет бригад → состояние «Подходящая бригада не найдена», не форсировать решение.
- Недостаточно прав → modal, состояние заявки не меняется.
- Ручная смена рекомендации → textarea обязателен, кнопка «Назначить» disabled пока пусто.
