# Проверочные сценарии

Источник: [tz.md](tz.md) §12–17, §29–34.

## Demo Mode

Неброская кнопка **Demo** → dropdown:

- Сбросить данные
- Симулировать конфликт
- Сценарий «нет свободных бригад»

После любого сценария — **Сбросить демо** для повтора.

## Начальное состояние

- Роль: Диспетчер
- Таблица открыта, drawer закрыт
- Заявка №10427 — «Требует назначения»
- Бригада №3 — свободна

---

## Happy path (обязательный)

```text
Открыть №10427
→ Выбрать автоматически
→ Рекомендация: Бригада №3
→ Назначить бригаду №3
→ Статус: Назначена, toast, таблица обновлена
```

## Conflict path (обязательный)

```text
Сбросить демо
→ Demo → Симулировать конфликт
→ Открыть №10428
→ Выбрать автоматически → Назначить
→ Modal: другой диспетчер назначил Бригаду №5
→ Обновить данные
→ Назначение: Бригада №5 (одно, без дубля)
```

## Permission path (обязательный)

```text
Сбросить демо
→ Роль «Бригадир»
→ Открыть №10427
→ Выбрать автоматически
→ Modal «Недостаточно прав»
→ Состояние заявки не изменилось
```

## No crew path (желательный)

```text
Demo → Сценарий «нет свободных бригад»
→ или заявка с Телеинспекцией (Мира, 22к1)
→ Выбрать автоматически
→ «Подходящая бригада не найдена»
→ [Обновить] / [Оставить на ручном назначении]
```

## Ручная смена рекомендации

```text
Выбрать автоматически → Выбрать другую
→ выбрать бригаду → указать причину → Назначить
```

Без комментария кнопка «Назначить» disabled. Причина сохраняется в state / истории.
