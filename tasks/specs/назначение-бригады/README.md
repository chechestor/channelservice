# Спецификация: назначение бригады на заявку

Демонстрационный React-прототип экрана **«Заявки на выезд»** для внутренней системы «Каналсервис».

## Цель

Показать полуавтоматический процесс:

**заявка → автоматический подбор бригады → подтверждение диспетчером → назначение**

и обязательные нештатные сценарии:

- конфликт параллельного назначения;
- недостаточно прав;
- отсутствие подходящей бригады.

Это **тестовое задание / демо-прототип**, не production.
