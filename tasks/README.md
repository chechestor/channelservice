Здесь ведётся техническая документация по работе: ТЗ, спецификации, критерии приёмки, сценарии.

Описание команды (роли и skills) — в [`team/`](../team/).

## Структура

```text
tasks/
├── README.md
└── specs/
    └── назначение-бригады/
        ├── README.md           # вход в спеку
        ├── overview.md         # краткий обзор
        ├── business-rules.md   # BR-01…BR-09
        ├── scenarios.md        # demo / проверочные пути
        ├── acceptance.md       # acceptance criteria
        └── tz.md               # полное исходное ТЗ
```

## Как работать с документами

1. Старт по задаче — `specs/<фича>/README.md`.
2. Реализация и проверка — `overview` + `business-rules` + `scenarios` + `acceptance`.
3. Детали UI, mock-данные, модели — `tz.md`.
4. Роль исполнителя — из `team/`.
