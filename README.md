# Каналсервис — прототип назначения бригады

Демонстрационный экран **«Заявки на выезд»**: заявка → взятие в работу → автоматический подбор бригады → подтверждение диспетчером → назначение.

По умолчанию открывается **доска**. Список — второй режим, с фильтрами (включая завершённые и отменённые).

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## GitHub Pages

Сайт: [https://chechestor.github.io/channelservice/](https://chechestor.github.io/channelservice/)

Публикация идёт автоматически из ветки `main` через GitHub Actions (`.github/workflows/deploy-pages.yml`).

1. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Закоммитьте проект и запушьте в `main`.
3. Дождитесь зелёного workflow **Deploy GitHub Pages** во вкладке **Actions**.
4. Откройте адрес выше. Первый деплой может занять 1–2 минуты.

## Основной сценарий

1. На доске открыть заявку №10427 (колонка «Новая»)
2. В модалке нажать **Да** — заявка перейдёт во «В работе», откроется карточка
3. Нажать «Выбрать автоматически»
4. Подтвердить Бригаду №3 — карточка перейдёт в «Назначена»
